# International Music Scales Atlas

**Development preview.** Features and examples may change. Corrections and feedback are welcome.

Start with D Dorian, or choose Shur to explore the Persian scale on any tonic. On a phone, add the Atlas to the home screen for standalone display. Select a geographic region to explore 216 documented tuning models across 17 navigation entries. Choose a category and tuning, then drag the inner diatonic ring to transpose in 50-cent steps. The outer circle preserves the ordered intervals. A degree selector explores rotations, and open spans retain their endpoints. Source interpretations remain under review.

The public catalog contains app-facing model metadata, tuning intervals, references and geographic navigation. The research workbooks and notes are private.

[Open the Atlas](https://persianmusicscales.github.io/international-music-scales-atlas/) · [Read the wiki](https://github.com/PersianMusicScales/international-music-scales-atlas/wiki) · [Report a problem](https://github.com/PersianMusicScales/international-music-scales-atlas/issues)

## Run locally

Run `python3 -m http.server 8000` from the project directory and visit http://localhost:8000. The application runs in the browser. Run `node --test atlas.test.mjs` with Node 22 or later to check the examples and diagrams.
